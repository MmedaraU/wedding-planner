# 💍 The Google Sheets Wedding Planner

Welcome! This project is a free, private, and mobile-friendly wedding planner. 

Instead of paying for a monthly subscription app, this project turns your personal Google Sheet into a beautiful, modern web app that you can access from your phone. Your data stays 100% in your control (in your Google Drive).

**What it does:**
*   **Live Dashboard (Overview):** Displays countdown, unified progress bars, and editable finance cards (Savings and Goals). Includes collapsible accordions for Wedding Details.
*   **Dynamic Budget & Finances:** Automatically calculates your "Available Cash" by adding your base savings and contributions, then subtracting the deposits you've paid. Supports quick-add for expenses.
*   **Guest & RSVP List:** Track who is coming, who is pending, and review auto-added RSVPs. (No hotel tracking clutter).
*   **Vendor Pipeline:** A fully dynamic A-Z list of vendors. Includes Quick Add (which automatically maps columns for Food vs. Wedding vendors) and auto-syncs "Chosen" vendors directly to the Team tab.
*   **Task Management:** A macro timeline for planning (sorted by date, with a section dropdown for Bridal) and a micro timeline for the Day-Of schedule.
*   **Merged Views:** 
    *   **Gifts & Cash:** Combined into one "To Thank" list.
    *   **Logistics:** Venue Runs, New Home, and Rentals merged into a single tab with inline status editing.
*   **Global Search:** Search across all sheets. Results are clickable and jump directly to the item.
*   **Automations:** Includes an Invitation Generator (Google Slides to PDF), Thank You Generator (Gmail drafts / WhatsApp links), and monthly email reminders.

## 🚀 1. How to Set It Up

### Step 1: Prepare the Google Sheet
Make a copy of the provided template. This sheet is your database. Ensure the following sheets exist:
*   `_app_config`: Tells the app which tabs to show, how to render them, and which sheets are vendors.
*   `_app_meta`: Holds key/value data. Crucial keys: `wedding_date`, `couple_names`, `savings`, `contact_email`, `savings_goal` (optional, defaults to 30M). Also requires the Named Range `Budget_Total_Deposits`.
*   `budget_flat`: A flat mirror of the budget (generated by the script).
*   `Guest List`: Must contain columns named exactly `Names`, `Guest Response`, `Number to expect`, `Category`, `How to invite`, `Invited to`. 

### Step 2: Set up the Backend (Apps Script)
1. Open your Google Sheet → **Extensions > Apps Script**.
2. Paste the code from `@OnlyCurrentDoc.txt`.
3. Find `const API_SECRET` and change it to a random password.
4. **Set up Permissions (Crucial):** Click the **⚙️ Project Settings** icon. Check *"Show 'appsscript.json' manifest file in editor"*. Go back to the Editor, click `appsscript.json`, and replace its contents with this block:
```json
   {
     "timeZone": "Africa/Lagos",
     "dependencies": {},
     "exceptionLogging": "STACKDRIVER",
     "runtimeVersion": "V8",
     "oauthScopes": [
       "https://www.googleapis.com/auth/spreadsheets",
       "https://www.googleapis.com/auth/drive",
       "https://www.googleapis.com/auth/presentations",
       "https://www.googleapis.com/auth/gmail.compose",
       "https://www.googleapis.com/auth/gmail.send",
       "https://www.googleapis.com/auth/script.send_mail",
       "https://www.googleapis.com/auth/script.external_request",
       "https://www.googleapis.com/auth/script.scriptapp"
     ],
     "webapp": {
       "executeAs": "USER_DEPLOYING",
       "access": "ANYONE_ANONYMOUS"
     }
   }
```

5. Click Save (💾).
6. In the dropdown menu at the top, select setupExistingData and click Run (Grant permissions).
7. Select installTriggers and click Run.
8. Deploy: Click Deploy > New deployment. Select Web app. Execute as: Me. Access: Anyone. Copy the URL — this is your planner API URL.
9. Set up Reminder Trigger: Click the ⏰ Triggers icon on the left. Add a trigger for sendCountdownReminders (Time-driven, Day timer, 8am-9am).

### Step 3: Set up the Frontend (GitHub Pages)

1. Fork this repository to your GitHub account.
2. Open config.js and paste your Web App URL.
3. Go to Settings > Pages, set the branch to main, and save.
4. Open your new GitHub Pages URL on your phone! The login screen will ask for the API_SECRET you set in Step 2.

## 📱 2. How to Use the App

· The Sidebar: Tap the ☰ icon to open the menu. Merged tabs (Gifts/Cash and Logistics) hide their underlying source sheets automatically.
· Editing: Tap the ⋯ (three dots) next to any item to open the editor. You can also edit your Savings Goal directly by clicking the cards on the Overview tab.
· Refreshing: The app saves data for 5 minutes to load fast. If you make a change in the Google Sheet and don't see it on the app, tap the Refresh button in the bottom left.
· Day-Of Schedule: Uses the Time column to render a chronological timeline. It uses .getDisplayValues() on the backend to prevent timezone conversions, so 8:00 AM always shows as 8:00 AM.
· Logistics: You can change the status of Venue/Home items via the inline dropdown, and mark Rentals as "Returned" without opening the editor.

## 📊 3. The "Golden Rules" & Admin Quirks

The app is smart, but it relies on the Google Sheet being formatted a certain way. Please follow these rules to avoid breaking the app:

1. Never insert rows above Row 1. Always insert new rows below the headers.
2. The Budget Mirror Quirk: The app uses a flat mirror (budget_flat) to stay fast. If you manually insert or delete an entire row in the main Budget sheet, you must click ⚙️ Workbook Tools > Refresh budget_flat from Budget. (Adding items via the app handles this automatically).
3. Available Cash Calculation: The app calculates Available Cash using Savings + Cash Contributions - Total Deposits. It reads the deposits from a Named Range called Budget_Total_Deposits.
4. Adding Vendors: To add a new vendor category, create a new sheet, add it to the _app_config sheet, and put a label in Column P (vendorKind).
5. The _app_config Tab Alignment (Day-Of Timeline): Because the Day-Of Timeline skips a few columns, it is highly sensitive to tabs. Ensure the row has exactly this layout:
   Day-Of Timeline | Day-Of Schedule | 1 | 2 | 1 | TRUE | 11 | (blank) | data | (blank) | Done | Activity | (blank) | Time | Activity,Time | (blank) | renderDayOfSchedule | FALSE
6. _app_config Guest List row, Column O (quickAdd). Set this to: Names,Category,Number to expect,How to invite,Invited to,Guest Response. Without this, guests added via + Add guest won't have an Invited to value, and the invite generator will skip them.
7. The "Refresh" button does NOT reload the schema. The sidebar "Refresh" button only clears row data. If you change column names, add new columns, or change vendorKind in the Google Sheet, you must hard-refresh the browser (Ctrl+Shift+R or Cmd+Shift+R).
8. visible: TRUE but Hidden in the Sidebar. For the merged tabs (Gifts & Cash, Logistics), their underlying sheets are set to visible: TRUE in _app_config. If we set them to FALSE, the backend stops sending their column headers to the app. We hide them from the sidebar by hardcoding their names into the HIDDEN_SHEETS array in renderNav() inside app.js.
9. nameField spelling must be perfect. In _app_config, the nameField (e.g., Task, Item, Vendor) is used by the backend to find the "true" last row of a sheet. If the spelling doesn't match the actual column header exactly, the backend will append new items to row 1,500.
10. Bridal List uses "Virtual Sections". The Bridal List doesn't have a physical Section column. Instead, it uses ALL CAPS text in the Item column. The backend scans the sheet to insert new items directly beneath the chosen ALL CAPS header.
11. Phantom Rows (Row 1500). If a sheet has checkboxes pre-filled down to row 1500, Google Sheets considers those "data". The backend deliberately ignores rows where the nameField is blank to prevent 1,500 ghost items from showing up.
12. Rentals use a Boolean Checkbox behind a Dropdown. The Rentals Tracker sheet uses a boolean checkbox for "Returned". The app renders a dropdown ("Needs return" / "Returned") to match other tabs. The backend translates the string back to a boolean when saving.
13. Vendor-to-Team Sync uses "Type" as the Role. When a vendor is set to any stage beyond "Waiting", they are added to the Team sheet using their Type as the Team Role. If you choose a second Photographer, it overwrites the first one in the Team tab. If you cut a vendor, it deletes them from the Team tab.

## 💌 4. Automations (Invitations & Thank Yous)

### Invitation Generation

1. Create Google Slide templates with <<Name>> on the actual slide canvas.
2. Run ⚙️ Workbook Tools > Generate ALL Guest Invitations.
3. The script skips physical cards and anyone who already has Generated in Column M. You can delete the word "Generated" to force a re-run.
4. The generator also skips any guest whose Invited to is blank. This is the safety net that prevents "RSVP (auto-added)" rows from getting a PDF before you've reviewed them.

### Thank You Generation

1. Ensure Gifts Received and Cash Contributions have Phone, Email, Thank You Method, and WA Link columns.
2. Run ⚙️ Workbook Tools > Generate Thank Yous.
3. Email: Creates a draft in your Gmail.
4. WhatsApp: Generates a click-to-chat link in the WA Link column.
5. In Person: Skipped automatically.
6. Rows are marked as DRAFT CREATED so you can run it multiple times without duplicating messages.

### Automated Reminders

The sendCountdownReminders script runs daily and sends an email on the 1st of every month (or if a task is overdue).

· Financial Goal: It dynamically calculates your total saved (Base Savings + Cash Contributions) against your savings_goal.
· Monthly Target: It divides the remaining balance by the months left to tell you exactly how much to save each month.
· Action Items: It pulls upcoming and overdue tasks from the Planning Schedule.
